# The Solver Mocks 🧠

**The Solver Mocks** is a speed practice and timed mock platform designed for competitive entrance exams, featuring automated test enhancers and interactive web interface.

---

## ✨ Modules & Practice Suites

- **⚡ Speed Boosters**:
  - **Quant Speed Boost**: Targeted calculations, speed drills, and quantitative short-tricks.
  - **Reasoning Speed**: Analytical puzzle speed tests and logical reasoning practice.
- **📚 Sectional & Full Mocks**:
  - **English Series**: Vocabulary, grammar, and sentence correction tests.
  - **GS Series**: General Studies and Static GK practice.
  - **Full Mocks**: Comprehensive multi-subject mock exams.
- **🛠️ Automated Test Enhancer**: Includes `enhance_all.js` script to format and optimize raw question datasets.

---

```
the-solver-mocks/

├── Reasoning Speed/      # Reasoning speed test series
├── English/              # English comprehension & grammar modules
└── GS/                   # General Studies mock series
```

---

## 🚀 Getting Started

Launch the web platform locally using Python or any static web server:

```bash
python -m http.server 8000
```

Navigate to `http://localhost:8000` in your web browser.
